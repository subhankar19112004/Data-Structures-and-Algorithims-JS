## ⏱️ Algorithm Complexity Reference

Understanding complexity is an essential part of writing efficient solutions.

| Complexity | Name | Example |
|---|---|---|
| O(1) | Constant | Hash Map Lookup (Average) |
| O(log n) | Logarithmic | Binary Search |
| O(n) | Linear | Array Traversal |
| O(n log n) | Linearithmic | Merge Sort |
| O(n²) | Quadratic | Nested Loop Traversal |
| O(2ⁿ) | Exponential | Subset Generation |
| O(n!) | Factorial | Permutation Generation |

## 💡 Problem-Solving Approach

For each problem, the focus is on understanding the underlying logic rather than memorizing solutions.

1. Understand the problem statement and constraints.
2. Identify the appropriate data structure or algorithmic pattern.
3. Develop a brute-force approach.
4. Optimize the solution.
5. Analyze Time and Space Complexity.
6. Implement the solution in JavaScript.
7. Test edge cases and boundary conditions.
